CROSS-CONTAINER TEST PROTOCOL

The third set gets proven the way the house proves everything: on real handsets, both platforms, face by face.

universal.apex-airsolutions.com

The testers

Android seat — the owner, on his handset. Apple seat — Kevin, full operator licence, on his Apple device. Same address, same shelf, same faces. Each tester works the full 56.

Android run (owner)

  1. Open universal.apex-airsolutions.com in Chrome. Confirm the shelf reads 56 faces.
  2. Open a face. Install it: browser menu → Install app (or accept the prompt). Confirm the icon lands on the home screen.
  3. Launch from the icon. PASS needs: full-screen, no browser bar; the clock live and ticking; the face's own function answering.
  4. Scan step: on the same card, download the depot Android APK. Verify the file's SHA-256 against the hash printed on the card before installing (any hash-checker app). Install the APK and run it — the same face in the native container.
  5. Airplane mode on. Relaunch the web container from its icon: it must open and run offline (the service worker carries it).
  6. Grade the face in the table: Container install · Runs · Offline · APK scan+run. Any failure gets its symptom written in Notes, in plain words.

Apple run (Kevin)

  1. Open universal.apex-airsolutions.com in Safari. Confirm the shelf reads 56 faces.
  2. Open a face. Tap Share → Add to Home Screen. Confirm the icon lands.
  3. Launch from the icon. PASS needs: full-screen standalone, no Safari bar; the clock live; the face's own function answering.
  4. Airplane mode on. Relaunch from the icon: it must open and run offline.
  5. Grade the face in the table. Apple has no APK column — the web container is Apple's container, and that is the point of the set.

What PASS means, per face

Installs from this one address · launches standalone · clock live · its listed function responds · offline relaunch works · layout holds at the device size, nothing overlapping, nothing cut. A face that fails any leg is a FAIL with the symptom named — never a quiet pass.

Known platform truth, stated before the test so nobody grades it as a defect: iOS gives no install prompt (the two Share taps are the road), and faces whose functions read device bridges (Wi-Fi scan class) answer through the native container on Android; in a web container they read their honest NO MEASURE, exactly as they do on the depot shelf.
