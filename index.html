What the universal container is — stated plain

Each face is one file. On this shelf that file is delivered as an installable web app: it installs to the home screen, opens full-screen with no browser bar, and after the first load it relaunches offline. The same face file rides inside the depot's Android APK — the native container — so Android carries two containers for every face and Apple carries the web container, all from this one address.

What it is not: on Apple it is not a native binary. Apple's rules give the web container as the store-free install — no App Store, no account, no third party holding this shelf. That is the Never-Again Storefront Law working as designed: the storefront sits in the house's hands.

Checkout, in the depot's own words: Posted shelf. Card checkout opens with the licensed launch; until then orders are reserved by email to sales@apexairsolutions.com and the house delivers the posted APK by link.
